# MOB CR

Browser version of Roger Blake's spreadsheet *MOB to CR BS Span ST DPT PAT Even*: converts measurement over balls to comparator readings, chordal dimensions and span dimensions for stub tooth herringbone gears/pinions with an even number of teeth.

`node test.js` checks all 133 formula cells against the original spreadsheet (L&H pinion LHMS10634).

Original app by Roger Blake.
